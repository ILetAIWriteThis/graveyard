# One good connection

## WHAT

A sentence pattern for a useful relationship:

> This could help with **that problem**, because **this specific mechanism**.

For example: a directory inventory helps write a project eulogy because it shows what actually exists without reopening every file.

## WHY

A category says where a thing belongs. A connection says when to think of it. The second is often what makes a saved thing useful months later.

## Keep it honest

One explained connection beats five vague ones. Shared topics are a good source of suggestions, but they do not prove a relationship. The site labels these suggestions separately from the caretaker's explicit connections.

Don't force a connection when none is apparent. An isolated interesting thing is allowed to exist here too.
