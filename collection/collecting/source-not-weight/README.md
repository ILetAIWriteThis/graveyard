# Keep the source, lose the weight

## WHAT

A preservation recipe for things too large or opaque to belong in this repository.

| The thing | What to save here |
| --- | --- |
| An executable | Source, build command, version, license, release URL |
| A useful PDF | Public URL, author, title, your short summary |
| A database | Schema or migration source, synthetic example, reconstruction notes |
| A large project archive | Relevant source, an inventory, setup notes, upstream URL |
| A video or image | Public URL and why it matters |

## WHY

The point is to preserve the possibility of understanding or rebuilding something. A folder of opaque artifacts can consume space without preserving that possibility.

## Caveats

Links can rot. Record titles, authors, dates where known, and enough original description to identify the work again. Do not use a public archive service for private content. A signed download URL may contain a credential.

Source code can also be sensitive or restricted by a license. “It's only text” is not a safety check.
