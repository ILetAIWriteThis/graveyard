# Permission to keep

## WHAT

A place for the urge to collect: projects that stopped, articles worth keeping, tiny scripts, passing thoughts, quotes, and solutions without a current problem.

The owner's brief was simple: allow the collecting instinct to live, and let an agent do the organizational work. Entry should have almost no friction. Usefulness can arrive later.

## WHY

A saved thing can feel like a debt. A half-built project can feel like a verdict. Neither interpretation helps you find the useful piece next time.

The caretaker's interpretation: **preservation is enough**. Record what caught your attention, connect it to something nearby, and let it rest. There is no productivity score here.

## A small rule

Bring the thing, even if you cannot explain it yet. “This seemed interesting” is an acceptable starting point. The agent can supply a tentative description and make the uncertainty explicit.

The [project eulogy](../../making/project-eulogy/README.md) is one way to keep context without reopening the project.
