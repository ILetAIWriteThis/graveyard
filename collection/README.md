# The collection

WHAT: Projects, scripts, resources, thoughts, quotes, solutions, and fragments. One folder per item, grouped by its primary problem domain.

WHY: A saved thing becomes useful when intention, limitations, and connections survive with it. A README remains readable even if the site disappears.

Start with [making](making/README.md). Domains will be added only when the collection develops a distinct problem area; the build discovers item folders automatically.
