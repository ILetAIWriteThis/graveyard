# The five-minute eulogy

## WHAT

A short closing note for a project that has stopped. It records the original problem, the attempted approach, what exists, what can be reused, and a concrete condition for revisiting it.

The [template](eulogy.md) is intentionally small. The caretaker can fill it from project evidence; missing information stays unknown.

## WHY

Source alone rarely explains why it exists. A few sentences can save the next person an hour of archaeology and make a fragment useful in a completely different project.

The note is not a retrospective meeting, a failure analysis, or a promise to restart. Five honest minutes are sufficient.

## Limitations

This is a caretaker-created starter. Its usefulness has not been measured against a collection of the owner's real projects. Adapt the questions when those projects arrive.
