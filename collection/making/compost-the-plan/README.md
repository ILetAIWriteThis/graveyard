# Compost the plan

## WHAT

A way to revisit unfinished work: separate the original plan from its useful parts. The project may be over while its parser, sketch, naming idea, test fixture, or explanation still has somewhere to go.

## WHY

Restarting a whole project carries its old assumptions and maintenance costs. Extracting one understood piece can solve today's smaller problem.

## Try this

Name one part you would keep if the original product could never ship. Explain what problem it solves. Connect it to another entry that has that problem. Leave the rest asleep.

This is a caretaker's suggestion, not an account of the owner's past projects. The first real burial will provide a better test of the idea.
