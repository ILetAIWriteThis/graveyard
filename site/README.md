# A walk through the grounds

WHAT: A static, accessible cemetery for unfinished things. Dark by default, with a remembered daylight setting. Browse headstones, search the index, follow connections, or dig up something at random.

WHY: A collection should invite rediscovery. Every item has a real URL and readable HTML even without JavaScript. All visuals are CSS and handwritten SVG; no images, external fonts, analytics, or browser dependencies.

`templates.mjs` generates HTML, `style.css` dresses the grounds, `app.js` adds discovery, and `theme.js` applies the saved lighting preference before paint.
